# 《自由未烬》游戏设计文档：数据附录

> 核对日期：2026-09-17；对应 Git 基准 `01d83a8` 及当时工作区内容。配合[系统设计正文](./游戏设计文档.md)阅读。此处保留代码 ID 以便开发者与 AI 定位，中文名称采用当前定义。

本附录从 TypeScript 语法树提取静态定义，并按系统整理。内容规模为 14 条法律、26 张卡牌、19 位顾问、46 个组织、128 个显式声明为 `GameEvent` 的对象。最后一项是静态定义索引，包含链节点及局部对象，**不是 128 个自动触发入口**，也不涵盖所有动态工厂生成的事件。

## C. 顾问目录

## G. 更新本附录时的约定

新增内容应同时核对实际注册入口，不能只按目录文件数统计；静态事件数量也不等于可游玩的完整事件链数量。更新数值时同步检查当前等级、选项条件、效果代码、预览与说明。删除或重命名 ID 前核对旧存档恢复与成就历史条件。若新增可玩党派，应在正文第 21 章的身份、组织、权限和评价层逐项建立对应，而非只扩充本附录的名称表。
