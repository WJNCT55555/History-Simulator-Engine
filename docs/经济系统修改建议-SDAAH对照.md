# 经济系统修改建议（对照 SDAAH）

> 对照对象：`docs/旧文件/SDAAH经济系统说明.md`（《Social Democracy: An Alternate History》v0.11.1，数值全部来自其源码）。
> 我方基线：`src/game/rules/economy.ts`、`rules/economyReforms.ts`、`docs/经济系统说明.md`。
> 本文只提建议，不含代码改动。

---

## 0. 两套模型的根本差异

| | SDAAH | 自由未烬（当前） |
| --- | --- | --- |
| 三指标的更新方式 | **离散增量规则**：每月按条件 ±0.1～0.4 | **惯性收敛**：`当前 + 惯性 × (目标 − 当前)`，惯性 0.35／0.30／0.20 |
| 目标从哪来 | 规则触发 + 历史冲击 + 政策冲量 | 由**水平量**算出：五档税率、债务、欠款、内战标志、`reformGraphs` |
| 财政 | `budget` 是**存量池，不自动补充** → 赤字是常态 | 流量瀑布：收入 → 现金 → 借债 → 欠款（`financing` 四级） |
| 指标是否会自己动 | **会**：赤字规则每月都触发，且每年有历史冲击砸一次 | **不会**：只要税率、债务、战争三项不变，指标 12 个月后进入不动点 |
| 约束 | 选举 + **资本罢工／政变进度**两条累积条 | 选举 + `stats.tension`、`republicanAuthority`、`coupProgress`（与经济活动基本不挂钩） |

**实测（我今天用只读探针跑的）**：1931 和平局、什么都不做 → 增长 1.20→**1.91**、通胀 1.40→**2.99**、失业 14.50→**13.13**，第 12 个月起**完全冻结**；1936 开战局同样什么都不做 → 三个数**每月都在动**（增长 3.50→−4.15、通胀 5.80→16.40、失业 12.00→19.43）。原因见上表最后一行：SDAAH 有"每月必然触发的规则 + 年度历史冲量"，我们只有"水平量算出的目标"，而水平量在和平局里全是常量（税率入口被沙盒开关挡住、没赤字、没战争，`reformGraphs` 恒零）。

## 1. 值得移植的九条（按性价比排序）

### ① 把宏观效果写进**行动**（最高优先，也最符合你已定稿的原则）

- **SDAAH 做法**：每个政策选项直接写死指标增量（如"加关税：通胀 +1、失业 +1.5、预算 +2"）。
- **我方现状**：`calculateEconomyReformGraphs()` 返回全零，18 个计数器对四个宏观修正的影响恰好是 0；六条路线日志的月度效果也已按你的定稿删除。结果：**"改造经济 → 指标变化"这条反馈是断开的**。
- **建议**：与所有权那次改动同构——**向量写在选项里，计数器只记账**。给每个经济选项补四个宏观增量（`growthGraph / inflationGraph / budgetGraph / foreignExchangeGraph`），然后删掉 `ECONOMY_COUNTER_TRANSFERS` 式查表的残留。
- **数值草案**（按"越彻底越疼"的历史逻辑，单位＝月度目标位移）：

| 行动 | 增长 | 通胀 | 财政 | 外汇 |
| --- | --- | --- | --- | --- |
| 农业合作社 / 工业合作社 | +0.15 | +0.1 | −0.15 | — |
| 土地征用 | −0.2 | +0.25 | −0.1 | — |
| 土地赎买 | +0.1 | +0.1 | −0.35 | −0.1 |
| 自愿 / 强制集体化 | +0.1 / **−0.5** | +0.15 / **+0.4** | −0.1 / −0.2 | — |
| 铁路 / 煤炭国有化 | +0.2 | +0.1 | **+0.4** | −0.1 |
| 外资没收 | +0.1 | +0.1 | +0.3 | **−0.6** |
| 银行没收 | **−0.8** | **+0.6** | +0.5 | −0.3 |
| 废除货币（1/2/3 级） | −0.2 / −0.4 / **−0.8** | +0.3 / +0.5 / **+0.8** | −0.2 | −0.4 |
| 物资调控 / 口粮本 | +0.1 / −0.1 | −0.3 / **−0.5** | −0.1 / +0.2 | — |
| 战时征发 / 外贸垄断 | −0.2 / −0.1 | +0.4 / +0.3 | +0.4 / +0.2 | +0.2 / +0.4 |

（这套系数与 SDAAH 的"加税/加关税/国有化"同量级：都是 0.1～1.0 的单次位移，靠每月累积出 3～8 点的差别。）

### ② 加一条**资本罢工**累积条，并把 `coupProgress` 与经济政策挂钩

- **SDAAH 做法**：`capital_strike_progress`（累进税、价格管制、福利扩张、国有化、赤字各 +1～3）与 `coup_progress`（无补偿国有化、工人接管、土改、司法改革、削军费）两条独立累积；阈值事件链：**≥6** 信心动摇（失业 +2、增长 −1）→ **≥10 或预算 ≤ −5** 资本罢工（失业 +5、增长 −4、右翼全体流向 NSDAP）→ `coup_progress ≥ 10` 进军柏林。
- **我方现状**：已有 `coupProgress`（0—100），但主要由暗杀、选举链、第四次代表大会驱动；**经济激进政策基本不影响它**，玩家也就感受不到"改造有政治代价"。
- **建议**：新增 `capitalStrikeProgress`（0—100，可读、能在侧边栏显示），让每个经济选项按"动了谁"给它 +1～5：累进税 +1、价格管制 +3、无偿国有化 +3、工人接管 +5、赤字每 2 点现金缺口 +1；阈值设在 40／70，触发两档事件（信心动摇 / 资本罢工），并让"资本罢工"用**已有的机制**结算（失业+、增长−、外汇−、右翼支持转移），不要新造一套。

### ③ 增长软上限 + 通缩惩罚（自稳对称化）

- **SDAAH**：`growth ≥ 7/10/12 → −0.1/−0.2/−0.3`；`inflation < −0.5 / ≤ −5 → 失业 +0.2/+0.3`；`inflation ≥ 7.5 且 growth ≥ 4 → growth −0.1`。
- **我方现状**：有 `deflationUnemployment {mild −0.5/+0.4, severe −5/+0.8}` 与 `growthBounds(−6..15)`、`inflationBounds(−5..100)`，**但没有过热自减**——只要外部条件好，增长可以一直顶在上限。
- **建议**：照抄三段过热自减（7/10/12 → −0.1/−0.2/−0.3），并把通胀的高位惩罚与③的资本罢工串起来（高通胀事件见⑥）。

### ④ 科研/教育的长期增长托底

- **SDAAH**：`science_bonus = education_science + applied_research×0.5`（上限 6）；增长低于 `bonus − 3` 时每月 +0.1。**教育科研是唯一"花钱买长期增长"的通道**。
- **我方现状**：`education_institutions`、`ateneos_established` 只作为**支出**出现（`monthlyPolicyCost`），对增长零回报。
- **建议**：把教育法等级 + 雅典学苑数 + 大学投入折成 `scienceBonus`（0—6），当增长低于 `bonus − 3` 时每月 +0.1。这条直接给"文化革命/自由雅典学苑"路线一个经济落点，也解释为什么共和国该在教育上花钱。

### ⑤ 历史年度冲量（长局最缺的"心跳"）

- **SDAAH**：1929 增长 −4；1930 失业 +6.8、通胀 −4；1931 失业 +6、通胀 −5、增长 −5（有工程计划可抵回）；1933 全球复苏；1934 通胀 +1。**全部按月摊成 /12**。
- **我方现状**：历史冲击主要写在**开局**（1931/1933/1936 三个剧本的初值）与若干事件里，缺少"每年砸一次"的节奏；1931 长局因此在 1932 之后没有任何外部经济事件。
- **建议**：给 1931／1933 加一条年度冲量表（1932 大萧条谷底、1933 全球复苏、1934 干旱/农业歉收、1935 军费扩张…），按月 /12 执行；**并且让玩家的路线能抵回一部分**（工程计划 ↔ 我们的"合作社 + 公共工程"），这正是 SDAAH 最有效的正反馈设计。

### ⑥ 高通胀危机事件（通胀 ≥ 8）

- **SDAAH**：五个应对——加税（通胀 −1、预算 +2、失业 +1.5、资本罢工 −1）、削福利（−1／+1／资本罢工 −2／工人 −5）、**价格与工资管制（通胀 −3、资本罢工 +3、失业 +1）**、求央行（资本罢工 +2）、无作为（资本罢工 +1）。
- **我方现状**：通胀上限 100，但没有专门事件；战时的 +8 通胀没有任何政治后果。
- **建议**：加 `high_inflation` 事件（通胀 ≥ 8），五个应对照抄思路，数值按我方量纲（通胀 −1～−3、财政 ±1～2、资本罢工 ±1～3）。

### ⑦ 福利跑步机（"什么都不做"也要付代价）

- **SDAAH**：失业 > 15 时，选"维持福利"等于 `welfare −1`；只有失业 ≤ 15 时维持才是真的维持。
- **我方现状**：福利/工时/最低工资是法律等级，只要不主动降级就没有维持成本。
- **建议**：失业 > 15（或 X）时，维持福利等级会把**欠款 +1**（"失业保险基金穿底"），或让实际福利等级 −1。逼玩家在"加税 / 削福利 / 让基金破产"之间选择，而不是无限期拖延。

### ⑧ 经济扩张计时器（正向累积奖励）

- **SDAAH**：连续正增长累积（赔款停付时翻倍）→ ≥85 且失业 ≤6、通胀 ≤6 时触发"经济扩张"事件：预算 +1、资本信心回升、全民支持上升、通胀 +0.4。
- **我方现状**：只有负反馈（债务、欠款、通胀），没有任何"经营得好会被奖励"的累积条。
- **建议**：加 `economicExpansion`（0—100）累积条，正增长且预算为正时累积，达到阈值触发一次"共和国经济复苏"事件（财政 +、外汇 +、中产/小业主支持 +）。

### ⑨ 赤字→通胀的三段阈值化（把连续式改成阶梯式）

- **SDAAH**：`0 ≥ budget > −2 → 通胀 +0.1`；`−2 ≥ budget > −5 → +0.2`（高失业时 −0.1）；`≤ −5 → +0.3`，并且每档都有上限（2.5／5／10）"打不动"。
- **我方现状**：`financingInflation = 新借债×0.5 + 新欠款×0.9` 是连续式，小赤字立刻有惩罚，玩家感受不到"小赤字不痛"的余地，也没有"越借越难借"的边际递减。
- **建议**：改为按**欠款/债务占总收入的比例**分三档（例如 <15% / 15—40% / >40%），每档给固定通胀增量并设上限；同时保留"高失业削弱赤字通胀效应"这一条（它让凯恩斯式刺激在高失业时更有效——SDAAH 用 −0.1 表达）。

## 2. 不建议照抄的三处

1. **存量制预算**。SDAAH 的 `budget` 不自动补充，是靠"每年 −1"制造长期压力；我们有完整的税基/征收效率/融资瀑布，改成存量会把财政系统砍成一半。**保留流量制**，但把"欠款"变成真正难受的东西（见 ⑨）。
2. **失业不做自然回归**。SDAAH 作者自己也承认失业只被事件与政策钉住。我们的"增长 ↔ 失业"耦合更合理，应保留，并补上 ④ 的增长托底。
3. **档位制税率**（−5…+5 相对 1928 基准）。真实百分比 + 税基容量曲线（`taxCapacity.threshold/slope`）信息量更大，也更适合"累进化/累退"之外的玩法。

## 3. 如果只做三件事

| 优先级 | 改动 | 解决什么 |
| --- | --- | --- |
| **P0** | ① 行动自带宏观效果（删掉 `reformGraphs` 的查表链） | 让"经济改造 → 三个指标"重新连上；这是当前最刺眼的断链 |
| **P0** | ② `capitalStrikeProgress` 累积条 + 与经济政策挂钩 | 给激进改造一条**可读的政治代价曲线**，替代现在散落各处的惩罚 |
| **P1** | ⑤ 年度历史冲量（1932—1935） | 让和平长局不再是直线；同时给"工程/合作社"路线抵回的机会 |
| P2 | ③ 增长过热自减 + ④ 教育科研托底 + ⑥ 高通胀事件 | 自稳与正反馈对称化 |
| P3 | ⑦ 福利跑步机 + ⑧ 经济扩张计时器 + ⑨ 赤字三段阶梯 | 打磨手感与边际体验 |
