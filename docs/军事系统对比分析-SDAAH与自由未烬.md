# 《自由未烬》×《Social Democracy: An Alternate History》军事系统对比分析

**评估命题：把 SDAAH 的军事系统用作《自由未烬》的和平时期（1931–1936）军事层**

- 文档性质：对比分析 + 移植可行性评估（非代码改动）
- 阅读材料：
  - `docs/SDAAH军事系统说明.md`（SDAAH v1.3.2 源码静态分析）
  - `docs/military-integration-design.md` v1.1
  - `docs/military-system-redesign-v2.md` v3.1 Final
  - 当前实现：`src/game/types.ts`、`src/game/organizations.ts`、`src/game/rules/{policy,policyDefinitions,income,economy}.ts`、`src/game/military_affairs/*`、`src/game/events/civil_war/civil_war_setup.ts`、`src/map/types_map.ts`、`src/game/GameContext.tsx:resolveBattle`
- 评分口径：★ 1–5，5 最好。同一维度下分别给出「原生表现」与「作为《自由未烬》和平期军事层的适配度」。

## 0. 结论速览

1. **方向正确。** SDAAH 的军事系统在结构上正是《自由未烬》目前最缺的一层：《自由未烬》已经有一套成熟的**战时**资产/地图战争引擎（v3），但**和平期**军事层目前是一个没有出口的仓库——`armaments`、`armedForces.militias.*`、`militiaCombatPower`、`entityPools` 在战争开局路径上仍然几乎零读取（`civil_war_setup.ts` 只读 `state.armies`/`INITIAL_ARMIES`，不读 `entityPools`）。
2. **但不能原样移植。** SDAAH 建模的是「**在朝的社民党对抗反民主准军事运动**」；《自由未烬》的玩家是「**既反法西斯又反国家的革命工会联合会**」。这带来三处必须改造的错位：缺少**军械获取轴**、忠诚必须是**按军种/地域分裂**的、敌方增长必须是**事件阶跃 + 阴谋时钟**而不是平滑年度曲线。
3. **最大收获不是数值，而是"杠杆"。** 《自由未烬》已经存在四条与 SDAAH 高度同构的制度轴——`public_order_law`、`security_corps_law`、`army_reform_law`、`militia_legality_law`（`src/game/rules/policyDefinitions.ts:179-213`）——但它们目前几乎全是 `No monthly effects`，只提供派系立场分数。SDAAH 的模型恰好可以把这四条**空转的法律**变成真正的军事杠杆（禁令是否被法院推翻、镇压是否可行、警察是否配合）。
4. **最关键的一条历史吻合。** SDAAH 的 `loyalty`（`strength × militancy × loyalty` 决定内战归属，初始 Reichswehr 忠诚 0.2 → 400 敌对战力）在西班牙史上比在德国史上更贴切：1936 年 7 月的军事政变本质上就是**国家武装按忠诚度自我分裂**。这是最值得移植、也最有戏剧性的单条机制。
5. **交接规则必须先写。** 和平期属性 → 战时实体池的转换必须显式、有阈值、可预览，否则五年积累要么变成无效装饰，要么变成开局雪球。v3 第 6.3 节的「准备率档位」已经是对的解药，缺的只是和平期一侧的产出定义。

**总评：SDAAH 方案作为和平期军事层，适配度 ★★★★☆（4/5）——结构最优，数值与轴需重铸。**

## 1. 为什么两套系统本来就该分工

| 维度 | SDAAH 军事系统 | 《自由未烬》v3 军事系统 |
|---|---|---|
| 时间尺度 | 1928–1933，**月/半年**级政治回合 | 1934 阿斯图里亚斯（3 天/回合）、1936 内战（1 月/回合） |
| 抽象对象 | 政治力量对比（人数 × 军事化 × 忠诚） | 属地战争（省份、补给、工业、三项资产） |
| 玩家动词 | 资助/削减、禁令/镇压、集会保护、驱逐、军费 | 征募、补充、移动、攻击、整编、分配军械 |
| 战争载体 | **一次公式结算**（三档阈值） | **持续地图战争**（多回合、多阵营、败亡条件） |
| 胜负颗粒 | 单一「内战战力比」 | 阵营败亡、首都 + 战略价值、三方化 |
| 主要张力 | 人数 ≠ 战力；武装自己会撕裂联盟 | 有限人力与重装备给谁；整编换取效率与政治后果 |
| 本质 | **和平期的政治—军事杠杆模拟** | **战时的资产—地图战争模拟** |

两者不是竞争关系，而是**同一条链的上下半段**。SDAAH 的强项恰好是《自由未烬》的短板，v3 的强项恰好是 SDAAH 完全不做的部分。**分工本身成立。**

## 2. 结构逐项对照

### 2.1 数据模型对照

| 概念 | SDAAH | 《自由未烬》现状 | 差异评估 |
|---|---|---|---|
| 组织规模 | 每组织独立 `strength`（千人） | `armedForces.militias.{cntFai,maoc,poum,ugt,requete,falange,africaArmy}`（人） | **结构相同**，粒度相当；SDAAH 多一层「正规军 vs 准军事」分类 |
| 训练/军事化 | 每组织独立 `militancy` 0–5 | 无。只有全局 `militiaCombatPower`（标量）与地图单位 `militarization` 0–100 | **SDAAH 明显更强**：能表达「CNT 人多但缺枪少训、Requeté 人少但军事化高」 |
| 忠诚 | 每国家武装独立 `loyalty` 0–1 | 单一全局 `stats.armyLoyalty` 0–100（`economy.ts:165` 由军费线性驱动） | **SDAAH 明显更强**：国民警卫/突击卫队/非洲军/半岛军官团的忠诚截然不同，全局标量无法表达 |
| 制度闸门 | `judicial_reform`、警察忠诚、内政部/普鲁士权限 | `public_order_law`/`security_corps_law`/`army_reform_law`/`militia_legality_law`（存在但空转） | **同构**：SDAAH 已把闸门接上效果，《自由未烬》只搭了骨架 |
| 政变/内战时钟 | `coup_progress`（多来源累积，含"削减军费 +1~+4"陷阱） | `coupProgress` 0–100，月度 `0.15 + tension×0.012 + (100−armyLoyalty)×0.025`（`policy.ts:108`） | **SDAAH 更强**：来源分散、可被玩家主动推高/压低，且与具体政策挂钩 |
| 军械/装备 | **无**（德国能买枪，不需要） | `armaments`（和平期每 2 月 +1，`income.ts:17-20`） | **《自由未烬》必须保留并升级**：这是西班牙的核心约束 |
| 敌方增长 | 年度表 + 事件驱动（SA 1929 +50 / 1930 +100 / 1932 +200…） | 无（Requeté/长枪党只有静态初始值） | **SDAAH 明显更强**：提供"时钟"与"不作为的惩罚" |
| 街头暴力 | `strife`（隐藏，影响中央党/DDP 去留） | 无对应物（`stats.tension` 部分近似） | SDAAH 更强，但西班牙需要换成「社会冲突 ↔ 联盟凝聚力」 |
| 战时资产 | 单一战力比 | 每实体 `{manpower, artillery, tanks}` + 地图单位 | **《自由未烬》明显更强** |

### 2.2 干预手段对照

| SDAAH 手段 | 西班牙对应物 | 现状 |
|---|---|---|
| 资助 Reichsbanner 军事化（成本递增 1→2→3，6 月冷却，上限 6 次） | 武装 CNT 防御委员会 / 民兵整编 | 已有 `militia_reorg`，但无成本递增、无上限、无对手 |
| 允许女性/同性恋者加入（力量 +400，军事化 ×0.85） | 自由女性（Mujeres Libres）、JSU 联合 | 组织已存在（`ML`），无军事效果 |
| 中央党/DDP 退出危机（militancy ≥0.2 时） | 与 PSOE/共和左派/加泰政府的联盟张力 | 有 `coalition_dissent`、`activeCoalitions`，未与军事化挂钩 |
| 禁 SA / 禁 Stahlhelm / 禁 RFB | 取缔长枪党 / 卡洛斯派 / 取缔 POUM、MAOC | 有 `militia_legality_law` 骨架，无效果 |
| 镇压 SA（需司法改革 ≥3 + 警察忠诚 ≥0.7） | 清洗右翼军官 + 治安部队忠诚审查 | 有 `security_corps_law` 骨架，无效果 |
| 驱逐希特勒（战力比对判定） | 逮捕/流放 Mola、Franco、Godet 等阴谋核心 | 已有 `francoStatus` 等旗标，但无战力判定 |
| 集会保护（警察战力 ×2 × 忠诚） | 街头冲突、葬礼/罢工的警民对峙 | 无 |
| 与 RFB 停战（`kpd_relation ≥45`） | 与 POUM/PCE 的联合行动 | 已有 `partyRelations`，v3 用 POUM ≥70 门槛——**同一设计模式** |
| 军费增减（−1/+1 预算，削减触发政变进度） | 军费 / 阿萨尼亚改革 | 已有 `military_policy` 卡与 `military_spending`，但后果比 SDAAH 温和得多 |

### 2.3 敌方增长机制对照

SDAAH 的对手是**会自己长大的**：

- SA：1929 +50、1930 +100、1931 +50（无就业计划则 +100）、1932 +200（无就业计划）+50（失业 >25）；
- Stahlhelm：1929/1930 各 +100、1931 +50；
- 事件驱动：Harzburg Front +100、信任投票失败 +200、进军柏林 +80、解除禁令 +100……
- 且**所有激进街头选项都会同时增强 SA（+40~+50）**——"街头对抗为纳粹提供招募素材"。

《自由未烬》目前**完全没有这个时钟**。`requete`/`falange` 的初始值一旦设定就基本不动，玩家在 1931–1935 期间"什么都不做"没有任何代价。这是和平期军事层最致命的缺失。

### 2.4 战争结算对照

| | SDAAH | 《自由未烬》v3 |
|---|---|---|
| 公式数量 | **3 套不同公式**（进军柏林 / 普鲁士政变 / 内战总决算），且系数互不相同 | 1 套统一 `CombatRules`（第 13.1 节） |
| 判定 | `>1.1×` 胜、`≥0.6×` 长期内战、否则彻底失败 | 首都 + 战略价值阈值 + 阵营败亡事务 |
| 参数化 | 硬编码在场景脚本 | `WarDefinition`（回合尺度、地图范围、胜利规则） |
| 工程风险 | **公式重复**是主要维护隐患 | 单一入口 + 资产守恒断言 |

> **可直接吸收的工程教训**：SDAAH 的三套公式是反面教材。《自由未烬》v3 的"唯一军事领域入口"清单（第 11 节）应当同样适用于和平期层——和平期的每一次 `strength`/`militancy`/`loyalty` 变更也必须走单一函数，否则会重演 SDAAH 的口径漂移。

## 3. 多维对比

### 3.1 历史准确性

#### SDAAH（在其自身题材内）：★★★★★

- 关键史实全部落地：Reichsbanner 200 万但 militancy 0.01（战力 20）vs Stahlhelm 50 万 × 0.5（战力 250）、SA 8 万、RFB 13 万；Reichswehr 忠诚 0.2（忠诚战力 100 / 敌对战力 400）；内政部警察 0.45、普鲁士警察 0.5。
- 制度史实精确：**法官解禁 SA**（`judicial_reform < 2` 时禁令被推翻）、镇压需司法改革 ≥3/≥4 + 警察忠诚 ≥0.7、禁 Stahlhelm 会掉 DVP 关系与普鲁士警察忠诚。
- 事件史实精确：Panzerkreuzer、Altona 血腥星期日、Blutmai、《西线无战事》、Harzburg Front、进军柏林。
- **核心历史洞见被建模出来**：民主派群众组织庞大但未军事化；极右人少但军事化程度高 50 倍。这正是魏玛崩溃的结构性原因。

**局限**：它是**党派政治史**，不是**军事史**。没有地理、没有装备型号、没有后勤、没有战区分工——对 1928–1933 的德国基本合理（没有内战），但无法表达任何作战层面的历史。

#### 《自由未烬》和平期现状：★★☆☆☆

- 现有实现把军事压成了几个抽象标量：全局 `armyLoyalty`、全局 `militiaCombatPower`、`armaments` 计数器。
- 史实颗粒度不足：没有军官团（Africanista vs peninsular）、没有 UME（西班牙军事联盟，1933）、没有 Mola 的阴谋计划（1936-03 起）、没有按军区的驻军忠诚、没有走私军械网络、没有手枪队（pistoleros）与 CNT 的起义周期（1932 Figols、1933 Casas Viejas、1933-12 起义）。
- 好的一面：制度轴名称是对的（阿萨尼亚改革、突击卫队组建、国民警卫队主导、工人巡逻队），`la_sanjurjada`（1932-08）也正确地把 `coupSystemActive` 打开——但打开之后只是每月涨 `coupProgress`，没有可操作的反制。

#### 《自由未烬》战时 v3：★★★★★

组织成立/解散日期、MAOC → 第五团、国际纵队分批抵达、CTV、Requeté、长枪党一线组织、统一法令、五月事件、POUM 站队门槛——颗粒度与史料审校清单（第 19 节）都达到可交付水准。

#### 移植后的历史准确性风险（关键）

把 SDAAH 的数值直接搬到西班牙会制造三类史实错误：

1. **"庞大但未军事化的民主民兵"在西班牙没有对应物。** CNT 1931 年会员约百万，但它不是 Reichsbanner——它本身就是**革命性**组织，且已有多次起义经验（1932、1933、1934）。若 CNT 以 `militancy ≈ 0.01` 开局，就把"武装不足"错写成了"不想武装"。
   - 西班牙的真正开局张力不是"人数 ≠ 战力"，而是**"有人、有意志、但没枪"**——即 `militancy` 高、`armaments` 低、且获取渠道被政治封锁（不干涉协定、共和国禁止武装工人）。
2. **"500 千 Stahlhelm"在西班牙不存在。** 1931–1935 年长枪党仅数千人、Requeté 约万余人；右翼准军事的爆发是**1933 大选后 + 1934 镇压后 + 1936 人民阵线胜利后**的阶跃，不是平滑年度增长。照搬 SA 的年度曲线会严重高估 1931–1933 的极右武装。
3. **"单一 Reichswehr 忠诚"在西班牙过于简化。** 共和国的国家武装至少分四块：国民警卫队（约 3 万，农村最受憎恨）、突击卫队（约 4 千，忠于共和国）、半岛陆军（军官团臃肿）、非洲军团（约 3–4 万，最精锐、最反动）。用单一 `armyLoyalty` 标量无法表达 1936 年 7 月"一部分军队叛乱、一部分忠于共和国、一部分观望"的事实。

> **判定**：结构（三属性乘法、政治代价、制度闸门）高度可移植；**数值、增长曲线、忠诚维度必须重铸**。

### 3.2 战略模拟性

| | SDAAH | 《自由未烬》v3 | 现有和平期 |
|---|---|---|---|
| 政治—军事联动 | ★★★★★ | ★★★★☆ | ★★☆☆☆ |
| 作战/空间/后勤 | ★☆☆☆☆ | ★★★★★ | ★☆☆☆☆ |
| 因果可解释性 | ★★★★☆（隐藏变量多） | ★★★★★（账本 + 月结原因） | ★★☆☆☆ |

- **SDAAH 模拟的是"武装自己的政治代价"**：资助民兵 → 军事化上升 → 中央党/DDP 威胁退出 → 联盟瓦解风险；削减军费 → 预算改善 → 但复员士兵流入 Stahlhelm/SA 且政变进度 +1~+4。这条因果链非常清晰，且**每一次选择都有对手反应**。
- **v3 模拟的是"有限资源在政治主体间的分配"**：实体池归属、军械分配、军事份额 vs 政治话语权失衡、凝聚力月结、L1→L2 的不可逆整编。它把"军队归谁"变成了可追踪的账本事实。
- **现有和平期几乎没有模拟**：军事卡是"投入换数值"，没有对手、没有时钟、没有反制、没有失败模式。

**关键判断**：SDAAH 与 v3 的模拟性是**互补**的，不是竞争的。SDAAH 补的正是 v3 明确声明"不做"的那部分（v3 第 2.3 节：军事系统不能吞噬政治主循环；第 1.1 节：不设置中央服从度、不设置动态政治授权）。

### 3.3 游戏性

#### SDAAH：★★★★☆

**优点**
- 单次行动的**决策密度**极高：每个选项都有可见的政治代价 + 延迟的军事收益。
- 成本递增（1→2→3）强制**排序**，不能一口气拉满。
- 敌方自动增长提供**时钟**，拖延有代价。
- 存在多个可行路线（武装 Reichsbanner vs 维持联盟；禁令 vs 镇压；驱逐希特勒 vs 攒战力）。
- 有**记忆点极强的陷阱**：削减军费在最坏情况下一次性 `coup_progress +4`。
- "RFB 可被 SPD 争取"（`kpd_relation ≥60`）提供了跨阵营的惊喜感。

**缺点**
- 全是菜单式资源分配，**没有战场**；战争是一段文本。
- `strife`、`judicial_reform`、`coup_progress` 大量隐藏，玩家容易感觉"看不懂为什么输了"。
- 一旦摸清最优序列，张力下降（重玩性中等）。
- 选项彼此独立性强，缺少"部队"这一层的中介，长期缺少养成感。

#### 《自由未烬》：和平期 ★★☆☆☆ / 战时 ★★★★☆

**和平期缺点**
- 军事卡是**可忽略的**：`militia_reorg` 只是 `-1 armaments` 换 `+5/+15 militiaCombatPower` 或 `+1000 民兵`；没有对手、没有冷却压力、没有失败可能。
- 玩家可以在 1931–1935 完全不碰军事，直到 1936 年照样进入内战。

**战时优点**
- 真实的地图操作：移动、攻击、征募、合并/拆分、解散、建设、AI 对手。
- `effectPreview.ts` 提供数值变更预览，UI 反馈远好于 SDAAH 的隐藏变量。
- 多阵营、三方化、败亡条件提供长线目标。

**移植后的游戏性增益（明确可预期）**
1. 和平期第一次出现**对手**（右翼准军事增长 + 军官阴谋时钟）。
2. 和平期第一次出现**反制手段的代价**（禁令会被法院推翻、镇压需要警察忠诚）。
3. 和平期第一次出现**"不作为的后果"**（1936 年 7 月叛乱成功的概率随军官团未被清洗而上升）。
4. 与战时无缝衔接：五年的每一个决定都能在 1936 年 7 月的地图上被"看见"。

### 3.4 难易程度

| 维度 | SDAAH | 《自由未烬》和平期现状 | v3 战时 |
|---|---|---|---|
| 入门曲线 | 中高（隐藏变量多） | 低（可忽略） | 高（地图 + 池 + 凝聚力） |
| 失败压力 | 高（开局战力差 12.5 倍） | 极低 | 高 |
| 难度旋钮 | **单一干净**：`rb_strength` 2500/2000/1000 | 仅切换事件触发模式（historical vs 非 historical） | AI 系数 0.95/1.00/1.05 + 搜索深度 1/2/3 |
| 雪球风险 | 有，但被 6 次上限 + 中央党退出危机抑制 | 无（因为无积累效果） | 有，被准备率阈值抑制 |
| 挫败感来源 | 隐藏变量导致"不知道为什么输" | 无 | 池断粮、凝聚力螺旋、POUM 门槛不可达 |

**判断**：
- SDAAH 的难度设计**明显优于**《自由未烬》现有和平期层，尤其是"单一难度旋钮"这一条。`rb_strength` 一个数字就能整体缩放难度，非常工程友好。
- 但 SDAAH 的隐藏变量问题不应照抄。《自由未烬》已有 `effectPreview` 与显式 UI，应把 `strength`/`militancy`/`loyalty`/`coup_progress`/`strife` 全部**显式展示**，让难度来自"权衡"而不是"信息不对称"。
- 建议为《自由未烬》和平期增设类似 `rb_strength` 的单一旋钮，例如「历史基准民兵池系数」或「右翼动员速率」，而不是只靠事件日期。

### 3.5 系统耦合与工程可维护性

| | SDAAH | 《自由未烬》v3 |
|---|---|---|
| 实现形态 | 场景脚本内标量算术 | 领域函数 + 事务 + 断言 |
| 单一规则源 | ✗（3 套战争公式） | ✓（第 11 节入口清单） |
| 存档迁移 | 简单（标量） | 复杂（`militarySchemaVersion: 3`，12 步迁移） |
| 测试成本 | 低 | 高（守恒、非负、唯一归属、固定种子） |

**建议**：和平期层应当刻意保持**廉价**——继续用标量，不引入实体池的复杂度；只在**交接点**（开战设置函数）做一次有明确规则的转换。这样既拿到 SDAAH 的可读性，又不把 v3 的工程负担提前到和平期。

### 3.6 玩家反馈与可读性

- SDAAH：四个准军事组织的 strength/militancy 在状态栏可见（`status.scene.dry:104-136`），但 `strife`/`judicial_reform`/`coup_progress` 基本隐藏。
- 《自由未烬》：`effectPreview.ts` 有完整的字段级预览，`organizations.ts` 有组织面板。
- **必须补齐的一块**：和平期 → 战时的**转换预览**。玩家应在 1936 年 7 月之前就能看到"我现在的 CNT 防御委员会 8,000 人 / 3 火炮 / 0 坦克，将在开战时变成什么"。这是让五年准备"有意义"的关键反馈，也是 SDAAH 完全缺失的一环。

### 3.7 与战时系统的衔接性（最关键维度）

| 方案 | 衔接性 | 说明 |
|---|---|---|
| SDAAH 原生 | ★★★★☆ | 输出是"单一战力比 + 归属判定"，极易转换，但**太薄**：一个数字无法生成三项资产池 |
| 现有和平期 | ★☆☆☆☆ | 已有 `entityPools`（`manpower/artillery/tanks`）但战争路径不读取；组织门控已实现，池仍是死水 |
| v3 目标 | ★★★★★ | 第 6 节已定义"历史基本盘 + 准备率阈值 + 骨干上限"，缺的是和平期一侧的产出定义 |

**结论**：SDAAH 是**正确的和平期形状**，但它的**输出必须被加厚**才能喂给 v3。详见第 6 节映射表。

### 3.8 扩展性与内容成本

- SDAAH：新增一个准军事组织 ≈ 加一行初始值 + 若干事件效果，**边际成本极低**。
- v3：新增一个武装实体需要组织定义 + 实体 ID + 池 + 事件链 + 存档键 + 测试，**边际成本高**。
- **推论**：和平期应承担"多组织、多小事件"的内容量（廉价），战时只保留少数高价值决策（昂贵）。这与 v3 第 2.3 节的设计意图完全一致。

## 4. 移植可行性逐项判定

| SDAAH 机制 | 判定 | 理由与做法 |
|---|---|---|
| 三属性乘法模型 `strength × militancy × loyalty` | **直接移植** | 结构通用，是本次移植的核心资产 |
| 军事化成本递增（1→2→3）+ 使用上限 | **直接移植** | 天然反雪球，且比 v3 的准备率阈值更早生效 |
| 每组织独立 `militancy` | **直接移植** | 修正现有全局 `militiaCombatPower` 的粗糙 |
| 国家武装 `loyalty` 决定内战归属 | **直接移植 + 拆分** | 必须拆为按军种/地域的多个 loyalty（见 5.3） |
| 敌方年度自动增长 | **需改造** | 改为事件阶跃 + 阴谋时钟（见 5.4） |
| 制度闸门（司法改革 + 警察忠诚） | **直接移植 + 激活** | 《自由未烬》已有四条同构法律轴，只需接效果 |
| 削减军费 → 政变进度 +1~+4（陷阱） | **直接移植** | 现有 `military_policy` 削减选项后果过轻 |
| 街头对抗同时增强敌方 | **直接移植** | 完美对应"镇压/冲突为长枪党提供招募素材" |
| 跨阵营盟友机制（RFB ↔ KPD 关系） | **直接移植** | 已有 `partyRelations` 与 v3 的 POUM ≥70 门槛，同一模式 |
| 集会保护公式（警察 ×2 × 忠诚） | **可移植（低优先）** | 西班牙对应街头对峙，可作事件判定 |
| 驱逐希特勒式"斩首"判定 | **可移植** | 对应逮捕 Mola/Franco，且已有 `francoStatus` 旗标 |
| 单一 `strife` 隐藏变量 | **需替换** | 改用「社会冲突 ↔ 联盟凝聚力」，与 v3 第 9.1 节共用 |
| 军费 → `economic_growth ±0.1` | **可移植** | 现有经济系统已能承接 |
| 德国式年度平滑增长曲线 | **不可移植** | 西班牙是阶跃式动员 |
| 无装备轴的纯政治模型 | **不可移植** | 必须新增军械获取轴 |
| 全国单一尺度 | **需地域化** | 至少按加泰/阿拉贡/瓦伦西亚/巴斯克/安达卢西亚/卡斯蒂利亚加权 |

## 5. 西班牙化改造清单

### 5.1 三属性轴的西班牙对应物

| SDAAH 属性 | 西班牙对应 | 初始设定建议 |
|---|---|---|
| `strength` | 组织可动员人数（CNT 会员、UGT 会员、JSU、Requeté、长枪党、MAOC） | 沿用现有 `armedForces.militias.*` 数值 |
| `militancy` | 武装化/训练/纪律程度 | CNT/FAI **不应从 0.01 起步**：已有起义经验，建议 0.15–0.3；但受军械上限压制 |
| `loyalty` | 对共和国 / 对革命 / 对敌方 的三向归属 | 见 5.3 |

### 5.2 必须新增的第四轴：军械与获取渠道

这是 SDAAH 完全没有、而西班牙不可缺失的一轴。

```
可部署武装 = min(组织成员, 军械可装备人数) × 军事化程度
```

- 西班牙的核心事实：1936 年 7 月巴塞罗那的工人有 3 万人排队，但军械库只有约 3 万支步枪且多数被封存。
- 军械来源必须**分渠道并各有政治后果**：
  - 走私/秘密采购（CNT 传统）→ 耗资源、低效、可被查获；
  - 兵营/军械库夺取 → 需事件与战力判定；
  - 苏联/墨西哥正式援助 → 进入国家渠道（v3 第 5.1 节已定），提高 PCE 影响；
  - 本国兵工厂 → 需控制工业区。
- 与 v3 的衔接：和平期 `armaments` 折算为**开战时的火炮/坦克/可装备人员**，而不是第四种库存（v3 第 6.5 节已有 `每点 = 250 名已具轻武器人员` 的迁移规则，可作为起点）。

### 5.3 忠诚必须拆分

现有单一 `stats.armyLoyalty` 应扩展为按武装主体：

| 武装 | 1931 建议忠诚 | 历史依据 |
|---|---|---|
| 国民警卫队（Guardia Civil） | 低 | 农村镇压主力，被工农憎恨，1936 年大量倒向国民军 |
| 突击卫队（Guardia de Asalto） | 高 | 1931 年新建，忠于共和国，1936 年 7 月在巴塞罗那镇压叛乱 |
| 半岛陆军军官团 | 低 | Africanista、UME（1933）渗透 |
| 非洲军团 | 极低 | 最精锐、最反动，1936 年叛乱核心 |
| 海军 | 分裂 | 1936 年水兵杀军官、舰艇多归共和国 |
| 空军 | 中 | 相对忠于共和国 |

**这一拆分是本次移植最有价值的产出**：它让"1936 年 7 月有多少军队跟着叛乱"变成一个由玩家五年决策塑造的连续变量，而不是历史常量。

### 5.4 敌方增长改为事件阶跃 + 阴谋时钟

不要照抄 SA 的年度曲线，改为：

| 触发 | 效果（建议方向） |
|---|---|
| 1933-11 右翼胜选 | 长枪党/Requeté 阶跃增长 |
| 1934-10 阿斯图里亚斯镇压后 | 右翼准军事扩张 + 军队声望上升 |
| 1936-02 人民阵线胜选 | 右翼恐慌性动员，长枪党激增 |
| 1936-03 起（Mola 阴谋） | `coup_progress` 每月上升，可被清洗/调职压低 |
| 街头冲突/罢工暴力 | 双方各增长，但右翼增长更快（历史逻辑） |

同时保留 SDAAH 的一条精髓：**镇压与对抗会同时增强对手**。

### 5.5 地域化

SDAAH 是全国标量；西班牙必须至少分区，否则无法与 v3 的地图战对接：

- 加泰罗尼亚（CNT 强、自治政府、公共秩序武装）
- 阿拉贡（CNT 集体化、前线）
- 瓦伦西亚（共和国中枢之一）
- 巴斯克（PNV、Euzko Gudarostea）
- 安达卢西亚（无地农民、CNT/UGT）
- 卡斯蒂利亚/纳瓦拉（右翼与卡洛斯派腹地）

建议和平期至少记录「区域组织密度 + 区域军械可得性 + 区域驻军忠诚」，作为开战时地图初始化的输入。

### 5.6 玩家身份双轨

SDAAH 的整套工具是为**在朝党**写的（内政部、普鲁士警察、司法改革）。CNT-FAI 可能是：

| `cntStance` | 可用工具 | 风险 |
|---|---|---|
| `govern`（入阁） | 国家工具：军费、治安部队清洗、民兵合法化法令、警政 | 被指"背叛革命"，派系不满 |
| `cooperate`（合作不入阁） | 工会渠道、议会施压、有限合法化 | 效率低 |
| `oppose`（反对） | 地下武装、走私军械、罢工、起义 | 被取缔、失去合法渠道 |

**这是 SDAAH 方案的最大结构性缺口**：它只有一轨。移植时必须为每一件国家工具准备一条**地下对应物**，否则 CNT 在野时将无牌可打。

### 5.7 激活四条空转的制度轴

| 法律轴（已存在） | 建议接上的军事效果 |
|---|---|
| `militia_legality_law` | 决定民兵能否合法征募、能否公开训练；0 级时武装行动触发取缔风险 |
| `security_corps_law` | 决定治安部队忠诚与镇压能力；4 级（工人巡逻队）把后方治安交给民兵 |
| `army_reform_law` | 0 级保留旧军官团 → `coup_progress` 加速；1 级阿萨尼亚改革 → 忠诚下降但清除阴谋核心；2 级重组 → 忠诚回升 |
| `public_order_law` | 决定镇压的合法性与社会反弹；2 级（共和国防卫法）解锁法外镇压但压低革命热情 |

这四条轴已经存在且已有派系立场分数（`policyDefinitions.ts:216+`），**接效果的边际成本很低，收益极高**。

## 6. 和平 → 战时的交接规则（映射表）

这是整个方案成败的关键。建议如下映射：

| 和平期变量 | 战时（v3）目标 | 转换规则建议 |
|---|---|---|
| 组织 `strength` | 实体池 `manpower` | 按组织对应实体（CNT → `cnt_defense_committees` → `cnt_fai_militias`），**先扣历史骨干部队**，余量入预备池（v3 第 6.4 节） |
| 组织 `militancy` | `EntityPreparation.readinessBonus` / 新单位 `combatReadiness` | 映射到 0–20 的骨干加成；不直接变成兵力 |
| `armaments` | 实体池 `artillery` / `tanks` + 可装备人员 | 沿用 v3 第 6.5 节：每点 → 250 名具轻武器人员；装甲车 → 2 坦克点 |
| 各武装 `loyalty` | **开战瞬间的阵营归属** | 直接决定哪些地图单位叛变（1936-07 设置链）、哪些忠于共和国 |
| `coup_progress` | 内战触发时机与政变成败判定 | 沿用 SDAAH 的战力比对；v3 的 `militarization` 不参与此项 |
| 区域组织密度 | `recruitmentRegions` / 地域可达系数 | v3 第 8.2 节阿斯图里亚斯可达系数（10%–40%）是现成模板 |
| 党派关系（POUM/PCE/PSOE） | 联盟凝聚力初值 / POUM 站队门槛 | 已有 `partyRelations` 与 POUM ≥70 门槛 |
| 派系分歧 | 联盟凝聚力月结 | 与 v3 第 9.1 节共用同一变量 |
| 军事化程度 | ⚠️ **不要**直接映射到 L0/L1/L2 | L0/L1/L2 是**战时制度整编**，只能由 1936-10 与 1937-02 的一次性事件推进（v3 第 7.3 节）。和平期军事化只影响 `readinessBonus` 与单位 `combatReadiness` |

### 三个必须避免的语义冲突

1. **"军事化"一词被三套系统使用**：
   - SDAAH 的 `militancy` = 组织武装化程度（和平期）；
   - v3 的 `RepublicMilitarizationState.level` L0/L1/L2 = 战时制度整编等级；
   - 地图单位 `militarization` 0–100 = 实际是 `combatReadiness`（v3 第 3.2 节已要求改名）。
   → **必须在命名上彻底区分**，否则玩家与实现都会混淆。
2. **`militiaCombatPower`（全局标量）与 `combatReadiness`（单位）并存**：应废弃前者，改为每组织 `militancy` + 每单位 `combatReadiness`。
3. **`armaments` 不得成为第四种库存**：它必须只有一个出口——按 v3 第 6.5 节折算，之后归零。

### 阈值而非线性（直接采纳 v3）

v3 第 6.3 节的准备率档位（<0.60 / 0.60–0.99 / 1.00–1.39 / ≥1.40）已经解决了"五年积累变成开局雪球"的问题。和平期层只需**输出可比较的准备率分子**，不需要自己定义战争后果。

## 7. 主要风险与陷阱

| 风险 | 成因 | 缓解 |
|---|---|---|
| 照搬德国数值造成史实失真 | Reichsbanner/Stahlhelm 无西班牙对应物 | 数值全部重铸，只移植结构 |
| 和平期层过重，拖垮政治主循环 | 引入实体池/账本到和平期 | 和平期保持标量；复杂度留在战时 |
| "军事化"三义混淆 | 三套系统共用词 | 重命名 + 文档标注 |
| 五年积累变成开局雪球 | 线性转兵 | 采用 v3 准备率阈值 + 骨干上限 |
| 在野玩家无牌可打 | SDAAH 只写了一套国家工具 | 为每件国家工具配一条地下对应物 |
| 敌方增长过快导致必败 | 阶跃事件叠加 | 用 SDAAH 式的难度单旋钮 + 可见预警 |
| 制度轴接效果后失衡 | 四条轴同时上线 | 分批接效果，先 `army_reform_law` 与 `militia_legality_law` |
| 忠诚拆分后 AI 无法处理 | 多忠诚目标 | AI 只读聚合值，细节仅供玩家与事件 |
| 与现有存档冲突 | 新增字段 | 全部 optional + 读取归一化（沿用 `normalizeOrganizationState` 模式） |

| 阶段 | 内容 | 验证 |
|---|---|---|
| **P0 语义与命名** | 区分 `militancy`（和平期组织）/ `combatReadiness`（单位）/ `RepublicMilitarizationState`（战时制度）；废弃 `militiaCombatPower` | 无玩法变化；build/lint |
| **P1 三属性模型** | 为每个武装组织加 `strength`/`militancy`；拆分国家武装 `loyalty` 为多主体；UI 显式展示 | 面板可见、旧档可读 |
| **P2 对手与时钟** | 右翼准军事的事件阶跃增长 + Mola 阴谋时钟（`coup_progress`）；街头对抗同时增强敌方 | headless 多路线跑 1931–1936 |
| **P3 制度轴激活** | 四条法律轴接军事效果（先 `army_reform_law`、`militia_legality_law`） | 镇压/取缔/清洗产生可追踪后果 |
| **P4 军械轴** | `armaments` 分渠道获取 + 政治后果；决定"可部署武装"上限 | 有人无枪状态可复现 |
| **P5 交接规则** | 开战设置函数读取和平期状态，按 v3 第 6 节生成实体池与准备率；提供**开战前预览 UI** | 三档准备都能进入可玩战争 |
| **P6 平衡** | 单一难度旋钮（历史基准池/右翼动员速率）；headless 曲线标定 | 高准备有优势但不锁死 |

---

## 9. 一句话总结

> SDAAH 的军事系统是《自由未烬》和平期层**最合适的骨架**——它把"武装自己的政治代价"和"不作为的惩罚"这两件目前完全缺失的事建模了出来；但它的数值与轴必须按西班牙史重铸：**加一条军械轴、把忠诚拆成军种与地域、把敌方增长改成事件阶跃与阴谋时钟，并为在野的 CNT 准备一套地下工具**。做完这四项，SDAAH 的和平期层与 v3 的战时层将形成一条从 1931 到 1939 的完整因果链。
