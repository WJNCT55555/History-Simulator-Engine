# 机制与理论

历史过程被表示为社会群体、政治主体、制度、组织与经济的相互作用。事件提供选择和外部冲击，世界状态决定行动可行性。这是一套可调参数的游戏模型，默认参数不具有普遍历史预测意义。

## 社会、组织和派系

每个群体有独立支持分布，合计 100；全国支持为群体权重归一化后的支持均值。支持变化采用有界零和转移：目标增加时按其他份额比例扣减，目标减少时按其他份额比例回流，其他份额全零时均分。份额非负，总量保持 100；单类别时保留全部份额。

组织覆盖与未组织人口合计 100，成立状态独立。一个主体的内部派系影响合计 100，异议各自为 0～100；纪律由影响加权异议得到，用于组织收入。支持、覆盖、派系影响和所有权分别守恒，不互相替代。

主体、组织、内部派系、军事阵营分别定义。同一主体可有多个组织与路线，多个主体可同属一个军事阵营，兵源可追溯到组织。支持增长通过卡牌、法律和周期规则等发生，不自动等于组织扩张。

## 议会与政策

有效票权重 = 全国支持 × 投票参与率。可参选主体按最大余数法分配作者指定的席位总数，余数相同以 ID 排序以便复现。

组阁需过半席位及成员关系达到阈值。内置组阁命令将配置职位交给玩家，细分分配可由事件 `office` 效果定义。失去多数或联盟关系不足时清除原联盟职位。参选资格、联盟与实际任职分别记录。

法律为等级序列，实施需要指定职位、组织资源与 AP；等级可增加国家月负担、修改宏观目标、执行社会月效果。主体可配置法律偏好，通过政策满意度指标参与条件。

## 财政与宏观

国家现金、债务、拖欠、黄金、外汇分别记账，组织资源另记。税收由税率、税基和效率决定；产出、就业、购买力、资本信心、贸易影响税基，超出税收能力阈值降低效率。支出包括行政、政策、军费、动员与债息。

赤字先用现金，再在融资能力内借债，剩余记为拖欠；盈余先清偿拖欠，再按规则还本金，剩余保留现金。增长、通胀与失业向政策、财政和外部冲击决定的目标渐进变化；真实产出按月增长演化。

提取时保留财政计算的税基权重、征收阈值、融资顺序和指标惯性，集中为 `ECONOMIC_RULES`；项目可用 `rules.economicProfile` 覆盖数值。年度冲击由 `economicShocks` 定义，不内置真实历史时间表。四组公式快照用于提取一致性回归。

## 内容与时间

一回合为一月。卡牌具有类别、入口费、冷却、份数、条件与选项；顾问占用槽位并有行动冷却。条件/公式读取真实指标，费用不足或权限失效拒绝整个交易。

事件区分自动入口和链内节点，独立配置日期、优先级、强制、重复与间隔。目标日志为未启动/进行中/完成/失败，奖励或惩罚只发一次；成就单调累积，结局按优先级选择并锁定。环境周期规则在财政前执行，社会规则在财政后执行，变量可建立危机、改革、压力与动员反馈。

## 战争与资产

地图通路与边界分别定义；地区有控制、地形、工业、战略价值与建筑。阵营敌对/中立关系独立于政治主体关系。

部队保留基础、支援、机动三个编制槽位，显示名称可改。总人数等于编制之和，支援和机动人数同时消耗来源装备。招募/补充扣来源人数、装备和阵营补给；解散返还剩余编制到原来源；拆分与同源同地区合并保持资产总量。

战斗保留部署宽度、人员/装备权重、来源组织化率、士气、地形、工事、随机波动、比例损失、增援和撤退：

```text
战力 = 已部署基础战力 × 来源组织化系数 × (1 + 士气 / 100)
       × 防守系数（防守方） × [0.90, 1.10] 随机系数
防守系数 = 1.2 + (地形系数 - 1) + 工事等级
```

RNG 注入并保存。战后按实际剩余人数记来源伤亡，被消灭部队不返还装备。阵营转移只改变归属，不复制资产。AI 使用相同规则，优先攻击相邻敌对地区中战略/工业价值较高者。

## 作者验证

群体权重/参与率、纪律对收入的作用、政策反馈方向、税收能力、融资上限、军事组织化与地形权重均是设计假设。结构校验保证引用和账本边界；历史解释、平衡、路径可达性与胜负节奏仍需通过研究和正常操作试玩验证。
