# 《自由未烬》法律可达性总表

> 审计对象：`src/` 全量源码（含 `dist` 之外的 `editor/`、`scripts/`，均无额外写入方）。
> 判定口径：**「有机会达到」= 游戏内存在写入该法律等级的代码路径，且在正常玩法（非沙盒改状态）下存在可达窗口。**
> 剧本范围：1931 / 1933 / 1936 三个剧本；难度范围：`easy / normal / hard / historical / sandbox`。
> 时间范围：1931·4 – 1939（`src/game/endings.ts:125` 以 `state.year >= 1939` 收束）。

## 0. 一句话结论

全游戏共 **14 部法律、66 个法定等级**，其中 **39 级正常可达、5 级需特定条件、22 级从任何正常路径都无法进入**。
`militia_legality_law`（民兵合法性法）**在整个游戏里没有任何写入方**——三个剧本都从 L1 开局，此后无任何内容能改动它；另外 9 部法律存在无法进入的等级（`public_order_law`、`union_status`、`land_law`、`womens_rights`、`religion_policy`、`education_institutions`、`language_policy`、`security_corps_law`、`army_reform_law`）。

## 4. 边界判定说明

### 4.1 `political_rights` L0「无选举」
唯一能把政治权利降到 0 的写入方是「吉尔‑罗伯斯当选 −1」，而 1933/1936 剧本开局已是 L2，故只可能出现在 1931 剧本：需在 **1931·12 宪法（+1）之前**让总统职位出缺（`propaganda_by_deed` 刺杀萨莫拉，或弹劾链）并在总统大选中支持吉尔‑罗伯斯获胜。窗口只有 1931·4–1931·11 的 8 个月，且要压过左翼票仓，属于**理论存在、实战极难**的路径，故记 🟡。

### 4.2 `language_policy` L2「自治双轨」
`catalonia_autonomy_1932` **没有剧本门控**，只要求「日期 ≥ 1932·9 + 政府类型为共和‑社会党内阁」。在 `historical` 难度下事件按精确月份触发（`src/game/utils/eventTrigger.ts:70-75`），1933/1936 剧本已过该月故永不触发；但在 `easy/normal/hard/sandbox` 难度下走条件触发，1933 剧本若通过政府危机 → 总统解散议会 → 提前大选（1935 年前左翼胜选）重建共和‑社会党内阁，该事件可再触发一次 → 语言政策 1→2。故记 🟡。

### 4.3 `security_corps_law` L2–L4（最典型的「有卡无路」）
唯一能推进该阶梯的是 `police_affairs`，其触发条件为 `cntStance === 'govern' && ministers.interior === 'CNT'`（`police_affairs.ts:48-51`）。而内政部长的全部写入方是：

- `elections_1931_results.tsx:448-451` —— **唯一**能给 CNT 内政部的入口：1931 组阁节点，内政部标价 **15 点筹码**，而 CNT 初始筹码正好是 15，必须梭哈。
- `casas_viejas.ts:74,114,168,207` —— 四个分支都会把 CNT 踢出内阁（内政部转 IR）。
- `elections_1933.ts:180,186-188` —— 无条件覆写全部部长并把 `cntStance` 置为 `oppose`。
- `rules/wartimeCoalition.ts:44-46` —— 战时三条组阁路线内政部**全部给 PSOE**。

于是正常玩法的窗口只有 **1931·7（三大后组阁）→ 1933·1（卡萨斯‑维耶哈斯）或 1933·11（大选）**，约 18–28 个月；警察事务卡冷却 6 个月，最多使用 **4–5 次，每次 +5 忠诚**，国民警卫队忠诚度上限 35 → 55/60，而 L2 门槛是 **70（国民警卫队）+ 90（突击卫队）**。全游戏只有 `police_affairs` 一个忠诚度来源（`raiseSecurityCorpsLoyalty` 的唯一调用点），因此 **L2 及以上在正常玩法下无法达成**。

> 例外：`sandbox` 难度的沙盒菜单可手动把内政部长改成 CNT（`SandboxMenu.tsx:82-90`），此时阶梯重新开放；但从 L1 走到 L4 需 15 次使用 × 6 月 = 90 个月，已等于 1931 剧本的全部时长，仍属极限操作。沙盒菜单本身**不提供**直接修改法律等级的控件。

### 4.4 关于难度与事件模式的差异
- `historical` 难度：带 `date` 的事件只在精确月份触发，1933/1936 剧本因此拿不到 1931–1932 的宪法、混合陪审团、阿萨尼亚改革、自治法令与共和国防卫法。
- 其余难度：带 `date` 的事件退化为条件触发，跨剧本补触发成为可能（见 §4.2），剧本开局值不变。

### 4.5 `public_order_law` 的新写入方（2026 补记）
本表出具后新增两个写入方，把 L1/L2 从死等级变为可达：`events/ley_defensa_republica.ts`（1931·10）与 `events/ley_orden_publico.ts`（1933·7）。

**共和国防卫法（1931·10，门控 `scenario === '1931'`）**
- **选项一（默认，史实 CNT 立场）**：拒绝承认该法 → **不改法律**。默认分支不改法律是刻意的：1933/1936 剧本描述符由 1931 剧本经真实 reducer 回放产生（`scripts/scenario-history-probe.ts`）；若默认分支改法律，回放路径就会与描述符分叉。
- **选项二**：要求写入司法保障 → `public_order_law = 1`（公共秩序法，受约束的紧急状态框架）。
- **选项三**：按原文支持 → `public_order_law = 2`（共和国防卫法，内政部获法外权），同时 `political_rights −1`，因此政治权利 L0「无选举」多了一条正常可达路径（1931·10 先降到 0，1931·12 宪法再升回 1）。

**公共秩序法（1933·7，门控「≥1933·7 且政府为共和-社会党内阁」，与 `catalonia_autonomy_1932` / `la_sanjurjada` 同款）**
- 该法在史实上**废止**了 1931 年防卫法，改为三级明定状态（预防／戒备／战争），因此「让法案通过」的两个选项都落在 **1 级**，只有「续行法外条款」的选项保留 **2 级**（并同样 `political_rights −1`）。
- 两个事件的默认选项组合起来，回放结果为 `public_order_law: 0 → 1`（1933·7），这正是 1933/1936 剧本描述符取 1 的依据（已用 `scripts/scenario-history-probe.ts` 验证到 1936·7 无进一步变化）。

**仍然死的是 L3 宪政与集会保障法案与 L4 公社防卫委员会。** 注意 `public_order_law` 的 L0 现在是「只有 1931 剧本开局那几个月能停留」的等级：1933/1936 剧本自 L1 起步，且没有任何降级写入方。
