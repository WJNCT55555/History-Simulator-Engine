## 一、机制设计

### 1.1 关键判断：冲量必须是"目标修正"，不能是"直接改值"

我方的三个指标是**惯性收敛**（`当前 + 惯性 × (目标 − 当前)`，惯性 0.35／0.30／0.20）。
所以：

- **直接给当前值加一笔**（SDAAH 的做法）在我们这套模型里会被**自动抹掉**——下一月它就朝没变的目标走回去；
- 必须把冲量写成**目标值的加项**（与今天的 `reformGraphs.growthGraph` 同位置），持续整年，
  这样它才会把三个数**稳定地推到新的水平**，年底换表时再移动一次。

### 1.2 数据形状

```ts
// types.ts（新增字段）
annualEconomicImpulse: {
  year: number;
  label: string; labelZh: string;      // 经济面板显示的一行说明
  growth: number;                      // 加在 targetGrowth 上
  inflation: number;                   // 加在 targetInflation 上
  unemployment: number;                // 加在 targetUnemployment 上
  foreignExchangeMonthly: number;      // 加在 tradeFxYield 上（外汇是流量型存量）
  goldMonthly?: number;                // 资本外逃年：每月扣黄金
  budgetMonthly?: number;              // 可选：每月财政增减（占领区/封锁）
};
```

### 1.3 生效时机与呈现（无需事件）

| 环节 | 做法 |
| --- | --- |
| 写入 | 月结里 `nextMonth === 1` 时静默写入当年冲量（不排队事件、不打断行动阶段） |
| 开局年 | 剧本开局若不是 1 月（1933·11、1936·07），在 `createScenarioState` 里先给当年那一行 |
| 读取 | `calculateMonthlyEconomy()` 的四个目标公式各加一项 |
| 呈现 | **经济面板一行**："本年外部经济环境：大萧条谷底（增长 −1.0／通胀 −0.8／失业 +1.2）"；另可在月结日志留一行，不进事件队列 |
| 难度 | 倍数：sandbox 0／easy 0.75／normal 1.0／historical 1.25 |
| 战争 | 战时年份（`civilWarStatus === 'ongoing'`）取"战时列"；`isCivilWar` 的 −6／+8／+4 结构项**保留不动**，战时冲量只表达"深化"（物资短缺、双重货币、失去工业区），所以数值刻意做小 |
| 冲抵钩子（可选，后置） | 用已有计数器/政策做减震：`agricultural_cooperative + industrial_cooperative` 每级减 0.1 失业冲击；`supply_coordination_network ≥ 2` 减 0.2 通胀冲击；`wartime_trade_monopoly ≥ 1` 减半外汇流失；关税 ≥ 25 减 0.3 外汇流失 |

### 1.4 年度冲量表（1932—1939）

和平列＝内战未爆发；战时列＝`civilWarStatus === 'ongoing'`。数值＝**月度目标修正**（持续 12 个月）。

| 年份 | 环境（中／英） | 增长 | 通胀 | 失业 | 外汇/月 | 黄金/月 |
| --- | --- | --- | --- | --- | --- | --- |
| 1932 | 大萧条谷底／Depression trough | −1.0 | −0.8 | +1.2 | −1.5 | −15 |
| 1933 | 谷底徘徊与复苏萌芽／Bottom, recovery in sight | −0.4 | −0.2 | +0.6 | −0.8 | −5 |
| 1934 | 缓慢复苏与农业危机／Slow recovery, agrarian crisis | +0.3 | +0.1 | −0.2 | +0.4 | — |
| 1935 | 复苏与丰收／Recovery and a good harvest | +0.6 | +0.2 | −0.6 | +1.0 | — |
| 1936 | 政治动荡与资本外逃／Unrest and capital flight | −0.8 | +0.6 | +0.3 | −2.0 | −25 |
| 1936 战时 | 战争爆发／War | −1.5 | +1.5 | +0.5 | −2.5 | −30 |
| 1937 战时 | 战时经济／War economy | −0.4 | +0.5 | +0.2 | −1.5 | −10 |
| 1938 战时 | 短缺与封锁／Shortages and blockade | −0.6 | +0.8 | +0.3 | −2.0 | −10 |

预期的量级（以 1931 和平局、默认税率、什么都不做为基线，实测不动点是 1.91／2.99／13.13）：
1932 年底增长 ≈ 0.9、失业 ≈ 14.4；1935 年回升到增长 ≈ 2.5、失业 ≈ 13.7；1936 年起随战局下行。
**长局从此不再是三条直线。**

## 二、历史经济新闻事件清单（单选项，news 类）

规则：**新闻＝一次性跳变；年度冲量＝持续 12 个月的环境**，两者不重复表述同一件事。
每条都是 `meta: { category: 'news', flow: 'solo' }` + `date` + **单个选项**（内容＝"把消息记入档案"）。
效果字段用我方现成的：`economy_growth`／`inflation_rate`／`unemployment_rate`（一次性跳变，建议用 `adjustUnemploymentRate`）、
`foreign_exchange`、`gold_reserves`、`budget`／`fiscal_arrears`、`resources`、`armaments`，以及 `relations`／派系支持。

## 四、三个待你确认的取舍

1. **冲量数值的量级**：现在的表是"1932 年把增长压低约 1 个点、失业抬高约 1.2 个点"。要更痛（×1.5）还是更温和（×0.6）？
2. **呈现方式**：只在经济面板显示一行（我的建议），还是同时写进月结日志／左侧新闻流？
3. **冲抵钩子**：要不要让合作社／配给／外贸垄断／高关税真的减震（§1.3 最后一行）？这会让"经济改造"多一层实际收益，但也更复杂。
