# 从项目到完整游戏

## 建立世界

启动 `npm run dev` 并打开 `/editor/`。“新建”提供最小世界；导入 `projects/demo/game.json` 可从完整演示改造。项目库可打开浏览器作品、磁盘作品与内置演示。

先设置 ID、名称、年月、玩家主体/阵营、初始资源、种子、议席与回合参数。稳定 ID 以小写字母开头，只含小写字母、数字、下划线和连字符。改 ID 不自动重写引用，校验报告指明修复位置。

建立主体、群体、派系、组织、所有权。增加主体给现有群体添加零支持项，随后自行调整分布。复制创建独立 ID；删除可撤销。最多保留 50 次定义变更。

## 制度和反馈

职位配置政策/财政/军事权限与任职者；法律配置所需职位、等级费用、国家月负担、宏观修正及月效果。税率和国家账本在参数中设置。

周期规则支持月度/年度，以及财政前的环境阶段/财政后的社会阶段。条件支持比较、全部、任一和取反；公式支持指标、常数、加减乘除、最小/最大值。指标目录在校验报告。变量可构建危机、改革与动员的跨系统反馈。

## 内容与剧情

制作卡牌、顾问、事件、目标、成就与结局。效果构造器支持资源、支持、派系、覆盖、所有权、关系、法律、职位、战争、地区、兵源及变量。按顺序执行，公式可读取之前效果的结果。

卡牌入口费与选项附加费分别设置，避免重复收费。每组决策保留无条件、无额外费用的继续选项，且其效果应在全部进入状态下可执行。校验能发现缺少这种出口，不能证明其效果永远成功。

选项的“后续事件”连接剧情，在链图查看；后续节点建议设“仅链内进入”。自动事件由年月/条件触发。强制事件必须处理后才能推进回合。链可循环，作者须保证出口；重复自动事件单独设置间隔。

目标定义开始/成功/可选失败条件、月效果、奖惩。结局按优先级选择并锁定，成就和目标完成会保存。

## 地图与军队

地图画布拖动地区示意位置。“编辑邻接连线”依次点击两个地区创建/移除双向通路。导入 GeoJSON 支持 Polygon/MultiPolygon 与孔洞，读取 `properties.id`/Feature ID、`name`/`NAME`、可选 `neighbors` 列表。不依据地理边界推断邻接，缺少通路时手工连线。

设置控制者、地形、工业、战略值、工事和建筑；定义阵营敌对/中立、兵源阵营/可选组织、人数/装备/组织化率与初始部队。人数必须等于编制合计且来源阵营一致。

来源后备是未部署余额，初始部队不再扣一次。运行时招募/补充/解散维护资产；拆分可以保留来源，只能合并同源同阵营同地区的部队。

## 素材与试玩

图片与音频支持 PNG/JPEG/WebP/GIF、MP3/OGG/WAV，单项约 12 MB。可设置卡牌/事件/结局图片、背景与音乐，音乐由玩家手动播放。素材内嵌，随项目和游戏导出。

校验通过后试玩真实引擎，查看费用、权限与效果预览；状态检查器显示运行状态。定义修改后“使用当前定义重新开局”更新试玩快照。

试玩与独立游戏保留原游戏的界面排布：左侧查看世界状态，中央处理事件和卡牌，底部任命顾问，右侧展开目标日志；顶部财政、政治、法律与法律立场打开弹窗，地图切换中央视图。游戏设置包含存档、重新开局和音乐播放。窄屏通过顶栏按钮展开状态栏。

至少验证开局、剧情链、行动、权限变动、月结、成功与失败路线；战争项目另验招募、补给、战斗、撤退与结局。存档需匹配项目版本和定义；修改后重新开局。

## 保存与交付

编辑期间保存浏览器草稿，未完成的份额/引用可保留修复。校验通过后“保存”写入浏览器项目库和 `projects/local/<id>/game.json`，可从项目库的磁盘列表打开。项目 JSON 用于备份、共享和 Git 管理；用户作品默认不提交，发布时将选定项目放入 `projects/<game>/`。

“导出游戏”下载单文件 HTML，可离线直接交付玩家：

```sh
npm run export -- projects/demo/game.json output/demo/index.html
```

静态部署的编辑器无磁盘服务，仍支持浏览器库和文件导入导出。大型素材可能超过浏览器存储额度，应及时保存文件。当前完整游戏制作范围是本机制的月度模拟；全新系统、兵种槽位或 UI 需扩展源码。
